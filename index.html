Projetos

Poupe.AI

Comparador colaborativo de preços de supermercado. Projeto Integrador III, CEUB, 2026.

Um app web para descobrir onde cada produto está mais barato perto de você, a partir de preços compartilhados pela comunidade.

  • Leitura do código de barras pela câmera e geolocalização para encontrar mercados próximos.
  • Servidor Node.js para consulta de notas fiscais eletrônicas (NFC-e).
  • Login e banco de dados no Supabase, com histórico de gastos e comparação da cesta do mês.
  • Organizado em sprints no GitHub, com issues, pull requests e documentação de arquitetura.

Feito com React 19, Vite, Tailwind CSS, Node.js e Supabase (PostgreSQL)

Socioeconomia vs. Desempenho no ENEM

Projeto de ciência de dados, 2026.

Uma análise de como fatores socioeconômicos se relacionam com as notas do ENEM, cruzando os dados do exame com indicadores do IBGE por estado.

  • Pipeline de ETL e análise exploratória em Python, com código organizado em módulos.
  • 20 indicadores (KPIs) calculados a partir dos dados.
  • Dashboard interativo em Plotly, publicado no GitHub Pages.
  • Próxima etapa: modelos de regressão e classificação.

Feito com Python, pandas, NumPy, Matplotlib, Seaborn, Plotly e Jupyter
